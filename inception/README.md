# Inception

Projet `Inception` de 42 avec `Nginx`, `WordPress` et `MariaDB` orchestrés par `docker-compose`.

## Démarrage

```bash
cd /home/kapi/Bureau/cpp/CPP/inception
docker-compose up --build
```

## Vérifications utiles

```bash
docker-compose ps
docker-compose logs -f
```

## Arrêt

```bash
docker-compose down
```
